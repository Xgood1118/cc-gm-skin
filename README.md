# 骨骼动画与蒙皮

两骨骼绑定的蒙皮烘焙器：读取 `data/rig.json`，按关键帧插值采样骨骼姿势，做线性混合蒙皮，
把每一帧全部顶点的世界坐标写到 JSON。只用 Python 标准库。

## 数学约定

- 矩阵为 4x4 行主序，**列向量**约定：`v' = M * v`。
- **父子矩阵乘法顺序**：`子骨骼世界矩阵 = 父骨骼世界矩阵 * 本骨骼局部矩阵`，
  即局部变换先作用于顶点，父级变换后作用；`bone_world_matrix` 从本骨骼递归乘到根。
- 局部矩阵 = `平移 * 绕 Z 旋转`（先旋转后平移）。
- **绑定姿势**：取每根骨骼的第一帧关键帧。蒙皮矩阵 = `当前世界矩阵 * 绑定世界矩阵的逆`，
  骨骼相对绑定姿势的偏移被扣除，因此静止时顶点坐标与输入完全一致（误差 < 1e-9）。
  逆矩阵按刚性变换求（旋转部分转置，平移取 `-R^T t`）。
- **权重**：每个顶点的骨骼权重归一到 1（除以非零权重之和），权重为 0 的骨骼直接跳过；
  顶点最终位置 = 各骨骼 `归一化权重 * 蒙皮矩阵 * 顶点` 之和。
- **插值**：位置线性插值；旋转角度差先折回 `[-180, 180)` 再插值，跨 180 度走最短路径，
  不会反向翻转。时间超出关键帧范围时钳制到端点，不外推。

## 运行

```
python gen_samples.py
python -m skin.cli data/rig.json --frames 12 --out frames.json
python -m pytest tests -q
```

`rig.json` 是两骨骼绑定：root 在 0 到 1 秒绕 Z 转 0 到 90 度并平移 1 个单位，arm 挂在 root 上
自转 -30 到 60 度。四个顶点里有一个跨骨骼混合权重。烘焙按 24 fps 采样，帧数与 `--frames`
一致；同一输入连续跑两次，输出逐字节相同（纯浮点确定性计算，无随机、无时钟）。

## 测试

`tests/` 覆盖：层级跟随（父平移/父旋转带动子骨骼）、权重归一（0.25/0.25 与 0.5/0.5 结果
相同、顶点不缩短）、零权重骨骼不参与、跨 180 度最短路径插值、端点钳制、静止帧与输入一致、
帧数与顶点数完整、两次烘焙逐字节相同。
