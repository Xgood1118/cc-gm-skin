# 骨骼动画与蒙皮

骨架能读绑定、能做线性插值、能烘焙若干帧，但蒙皮结果在数学上是错的。

## 已知缺口

- `bone_world_matrix` 只看本骨骼的局部变换，不乘父骨骼矩阵，手臂不会跟着躯干走。
- `skin_vertex` 只取第一个骨骼的权重，第二个骨骼完全被忽略。
- 权重不做归一，构造数据里有一个顶点权重和是 1.0，另一个是 0.7 加 0.3，
  当前实现会让权重 0.7 的顶点整体缩小 30%。
- 插值用欧拉角，`rot` 从 90 到 -90 会走长路径穿过 0，出现翻转。
- 绑定姿势的逆矩阵没有参与计算，骨骼原点被当成世界原点。

## 运行

```
python gen_samples.py
python -m skin.cli data/rig.json --frames 12 --out frames.json
python -m pytest tests -q
```

`rig.json` 是两骨骼绑定：root 在 0 到 1 秒绕 Z 转 0 到 90 度并平移 1 个单位，arm 挂在 root 上
自转 -30 到 60 度。四个顶点里有一个跨骨骼混合权重。
