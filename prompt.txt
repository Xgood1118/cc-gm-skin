## 需要完成

1. **层级变换**
   - 子骨骼必须跟随父骨骼运动，arm 的世界位置在 root 平移后要同步移动。
   - 父子矩阵的乘法顺序要有明确方向，并在 README 里说明。

2. **权重**
   - 多骨骼权重必须归一到 1，两个骨骼各 0.5 的顶点在骨骼分离时不能缩短。
   - 权重为 0 的骨骼不能参与计算。

3. **插值**
   - 旋转角度跨越 180 度时要走最短路径，不能出现反向翻转。
   - 关键帧范围外的时间要钳制到端点，不能外推出超范围姿势。

4. **绑定姿势**
   - 骨骼相对绑定姿势的偏移要正确扣除，静止时顶点坐标与输入完全一致（误差 1e-9）。

5. **输出**
   - 每帧输出所有顶点坐标，帧数与 `--frames` 一致。
   - 同一输入连续跑两次，输出逐字节相同。

6. **测试**
   - 覆盖：层级跟随、权重归一、跨 180 度插值路径、端点钳制、静止帧与输入一致。
   - `python -m pytest tests -q` 全部通过。
